# Bienescrivere e Pronunzia

Bienescrivere e pronunzia standarda 

## Li Vocali

| Grafema | Fonema |
| :--- | :--- |
| a | /a/ |
| e | /e/, /ɛ/ |
| i | /i/ |
| o | /o/, /ɔ/ |
| u | /u/ |
| à | /a/ |
| é | /e/ |
| è | /ɛ/ |
| ì | /i/ |
| ò | /ɔ/ |
| ù | /u/ |

Li vocali innele sillabe toniche li han diacritici suso esse quando l'ultima sillaba l'è la tonica. Quando la tonica l'è l'antepenultima, el non ne v'è, ma a volte si utilizza per dimostrarlo, bien ch'el non sia obbligatoio.
