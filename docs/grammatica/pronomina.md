# Le Pronomina

Vi son dui tipi principali di pronomina: le pronomina indipendiente e quelle dipendiente. Le pronomina dipendiente li vegnen prima de lo verbo, mientre che quelle indipendiente non le son obbligatoria.

| Persone | Indipendiente                                                                        | Dipendiente | Possessiva |
| ------- | ------------------------------------------------------------------------------------ | ----------- | ---------- |
| P1      | eo                                                                                   | i           | -me        |
| P2      | tu                                                                                   | tu, t'      | -te        |
| P3      | egli (masc. umano), ella (fem. umano), esso (masc. non-umano), essa (fem. non-umano) | el, l', la  | -se        |
| P4      | noi, noialtri (escludiente)                                                          | no          | -ne        |
| P5      | voi                                                                                  | vo          | -ve        |
| P6      | elli (masc. umano), elle (fem. umano), essi (masc. non-umano), esse (fem. non-umano) | li, le      | -se        |

In arnoldesco l'è assai commun l'espression de la possession cun suffisso pronominale lego a lo sustantivo. a.e.: ***la casa-me, lo libro-te, la sposa-se, li mariti-ve***, ecc.
