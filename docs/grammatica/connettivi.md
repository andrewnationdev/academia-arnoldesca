# Preposizioni, Coniunzioni ed Avverbi
Qui te tu puoi imparar come rendere le proposizionite più dinamiche.

## Preposizioni
Le preposizioni le son le parole che le collegan li elementi.

| Semplici         | Co li articoli                                 |
| ---------------- | ---------------------------------------------- |
| *a*              | *al, ai, a li, a lo, a la, a le*               |
| *con*            | *col, coi, co li, co lo, co la, co le*         |
| *da*             | *dal, dai, da li, da lo, da la, da le*         |
| *de, di*         | *del, dei, de li, de lo, de la, de le*         |
| *contra*         | *-*                                            |
| *senza, assenza* | *-*                                            |
| *tra, fra*       | *-*                                            |
| *suso*           | *sul, sui, su li, su lo, su la, su le*         |
| per              | pel, pei, pe li, pe lo, pe la, pe le           |
| *en, in*         | *innel, innei, inneli, innelo, innela, innele* |
| *en, in*         | *indel, indei, indeli, indelo, indela, indele* |

## Avverbi

Li avverbi li modifican li verbo o li aggettivi.

| Categoria         | Avverbi                                  |
| ----------------- | ---------------------------------------- |
| **Luoco**         | *qui, labassu, giù, là, lì*              |
| **Tiempo**        | *mo, ormai, oramai*                      |
| **Frequenza**     | *siempre*                                |
| **Negazion**      | *non*                                    |
| **Affirmazion**   | *sì*                                     |
| **Possibilitade** | *fortasse, forsi, probabilmente*         |
| **Maniera**       | *bien, male*                             |
| **Interrogativi** | *come, ove, onde, donde, perché, quanto* |
| **Quantiti**      |                                          |

## Coniunzioni
Le coniunzioni in arnoldesco le collegan le frasi e le proposizioni, stabiliendo una relazion semantica tra esse.
### Coniunzioni Coordinanti

| Categoria       | Coniunzioni               |
| --------------- | ------------------------- |
| **Contrasto**   | *ma, però*                |
| **Spiegazion**  | *perché*                  |
| **Conclusion**  | *donde, pertanto, perciò* |
| **Alternativa** | *o, od, sia X sia Y*      |
| **Addizion**    | *e, ed, ed anco, ma anco* |
### Coniunzioni Subordinanti

| Categoria         | Coniunzioni                         |
| ----------------- | ----------------------------------- |
| **Causali**       | *visto che, dato che*               |
| **Concessioni**   | *bien che*                          |
| **Condizionali**  | *se*                                |
| **Conformative**  | *secondo, suso*                     |
| **Finali**        | *????*                              |
| **Proporzionali** | ???                                 |
| **Temporali**     | *quando, siempre che, avanti, dopo* |
| **Comparative**   | *quanto, come*                      |
| **Integranti**    | *che, se*                           |
