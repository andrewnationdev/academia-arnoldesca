# Coniugazione Verbal

## Li Verbi Ausiliari ESSE ed AVERE
Li verbi ausiliari più importanti li son messi qui sotto:

Presente de l'Indicativo

| Persona    | Esse           | Avere (ausiliare)    | C'avere (possession)     |
| ---------- | -------------- | -------------------- | ------------------------ |
| eo         | i son          | i ho                 | i c'ho                   |
| tu         | t'è, tu sei    | t'hai                | tu c'hai                 |
| egli, ella | l'è            | l'ha                 | el c'ha, la c'ha         |
| noi        | no semo        | no avemo, no abbiamo | no c'avemo, no c'abbiamo |
| voi        | vo siete       | vo avete             | vo c'avete               |
| elli, elle | li son, le son | l'han                | li c'han, le c'han       |

## Paradigma di Coniugazione General

### Prima Coniugazion (-ARE, -AR, -À)

| Persone    | Presente | Preterito Perfetto | Preterito Imperfetto | Futuro |
| ---------- | -------- | ------------------ | -------------------- | ------ |
| eo         | -o       | -ai                | -ava                 | -arò   |
| tu         | -i       | -asti              | -avi                 | -arai  |
| egli, ella | -a       | -ò                 | -ava                 | -arà   |
| noi        | -amo     | -ammo              | -avamo               | -aremo |
| voii       | -ate     | -aste(vo)          | -avate               | -arete |
| elli, elle | -a(n)    | -aro               | -ava(n)              | -aran  |

| Persone    | Condizional | Presente Cong. | Imperfetto Cong. | Piuperfetto |
| ---------- | ----------- | -------------- | ---------------- | ----------- |
| eo         | -aria       | -i             | -assi            | avia PCP    |
| tu         | -arie       | -i             | -assi            | avie PCP    |
| egli, ella | -aria       | -i             | -asse            | avia PCP    |
| noi        | -ariamo     | -iamo          | -assemo          | aviamo PCP  |
| voii       | -ariate     | -iate          | -aste            | aviate PCP  |
| elli, elle | -aria(n)    | -i(no)         | -asse(ro)        | avian PCP   |

| Persone | Imperativo Aff. | Imperativo Neg |
| ------- | --------------- | -------------- |
| Tu      | -i              | non + INF      |
| Voi     | -iate           | non + -iate    |

| Forme              | Terminazioni |
| ------------------ | ------------ |
| Infinitivo Pieno   | -are         |
| Infinitivo Ridotto | -à, -ar      |
| Participio Pieno   | -ato         |
| Participio Ridotto | -o           |
| Gerundio           | -ando        |
